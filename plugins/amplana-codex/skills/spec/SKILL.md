# Amplana Spec (deprecated)

`amplana:spec` was renamed to `amplana:brief` in 1.2.0 and will be removed in a later release.

1. Tell the user in one line that `amplana:spec` is now `amplana:brief`.
2. Read `../brief/SKILL.md` (the `amplana:brief` skill in this plugin) and follow it with the user's request unchanged. The output files are the same (`specs/{feature-name}/spec.md`, `technical-spec.md`, and so on).
